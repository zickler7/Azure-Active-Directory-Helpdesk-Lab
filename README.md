# Azure-Active-Directory-Helpdesk-Lab
Cloud-hosted Azure lab simulating Tier 1/2 IT Support. Deployed Windows Server (dc01) in resource group rg-helpdesk-lab, configured Active Directory Domain Services (AD DS) and DNS. Built to practice identity management, user provisioning, Group Policy (GPO), and enterprise administration.

## 📌 Project Overview
Built a cloud-hosted enterprise environment in Microsoft Azure to simulate real-world IT Support (Tier 1/2) scenarios, including Active Directory management, DNS configuration, Group Policy deployment, and role-based access control.


## 🛠️ Infrastructure & Tools
* **Cloud Provider:** Microsoft Azure
* **Resource Group:** `rg-helpdesk-lab`
* **Virtual Machine:** `dc01` (Windows Server)
* **Active Roles:** Active Directory Domain Services (AD DS), DNS Server


## 🚀 Key Tasks Completed

### 1. Cloud Infrastructure Provisioning
* Created a dedicated Virtual Network (VNet) and Network Security Group (NSG) in Azure.
* Provisioned and deployed the Windows Server instance `dc01`.

### 2. Domain Controller Setup
* Promoted `dc01` to an Active Directory Domain Controller.
* Installed and configured core **AD DS** and **DNS** roles.
